# AI Platform Engineering Portfolio

This repository contains a collection of production-grade projects built as part of a comprehensive AI Platform Engineering bootcamp. The projects demonstrate end-to-end skills in building, deploying, and operating LLM-powered systems on Kubernetes.

## Projects Overview

| # | Project | Focus Area | Key Technologies |
|---|---------|------------|------------------|
| 01 | RAG System with Vector Databases | Retrieval Augmented Generation | Chroma, pgvector, LangChain, Kubernetes |
| 02 | AI Agents for Platform Engineering | Agentic Workflows & Tool Use | LangGraph, ReAct, Kubernetes Tools, Multi-Agent |
| 03 | MLflow for LLMOps | Experiment Tracking & Model Registry | MLflow, PostgreSQL, MinIO, Kubernetes |
| 04 | Kubernetes Resource Management for ML | Inference Workload Optimization | ResourceQuota, LimitRange, QoS, VPA |
| 05 | AI Observability for LLM Systems | Production Monitoring & Evaluation | Prometheus, Token Tracking, LLM-as-Judge, Cost Attribution |
| 06 | Platform Engineering Assistant (Capstone) | End-to-End AI Platform | RAG, LangGraph, Ollama, Vault, Helm, Prometheus |

## Skills Demonstrated

- **Platform Engineering**: Kubernetes, Helm, GitOps, resource management, observability
- **LLMOps**: Prompt tracking, evaluation pipelines, cost control, quality monitoring
- **AI Engineering**: RAG architectures, agentic systems, model serving, evaluation frameworks
- **Production Readiness**: Structured logging, metrics, alerting, graceful error handling
