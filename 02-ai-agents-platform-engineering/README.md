# Project 02: AI Agents for Platform Engineering

## Overview

This project builds a suite of production-grade AI agents designed for platform engineering use cases, including Kubernetes troubleshooting and infrastructure operations.

## Projects Included
- Basic ReAct Agent
- Platform Assistant with Kubernetes tools (get_pods, logs, describe)
- Human-in-the-Loop Approval Workflow
- MCP Server (Model Context Protocol)
- Multi-Agent Supervisor + Specialist system

## Key Features
- Safe tool execution with guardrails
- Human approval for dangerous operations
- Standardized tool interface via MCP
- Supervisor routing for complex tasks

## Technologies
- LangGraph
- LangChain
- Kubernetes Python client / subprocess
- FastAPI (for MCP Server)
